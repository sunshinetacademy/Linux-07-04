1 افتتاحية: من الـ ping اليدوي للسكوت الذكي 😎

افتكروا المحاضرة اللي فاتت؟ في تمرين رسم خريطة الشبكة، كنا بعمل ping لعنوان عنوان عشان نكتشف الأجهزة... تعبنا، صح؟ 😅

تخيلوا شبكة فيها 254 جهازًا — هنحتاج 254 أمر ping باليد! أما مع Nmap:

الفرق بين البطل والمستخدم العادي
# الطريقة اليدوية (المحاضرة اللي فاتت):
$ ping 192.168.1.1
$ ping 192.168.1.2
... × 252 مرة 😴
# طريقة المحترفين:
$ nmap -sn 192.168.1.0/24
← الشبكة كلها في ثواني ⚡

💡 الدرس الأهم: Nmap مش "سحر" — هو بعمل نفس حاجات الـ ping اللي اتعلموها، بس بسرعة وذكاء وتوازي. عشان كده اتعلمنا الأساس الأول!

2 المنافذ (Ports) — أبواب المبنى 🚪

تخيل إن كل جهاز على الشبكة مبنى كبير 🏢، وعنوان IP هو عنوان المبنى. طيب المبنى فيه آلاف الأبواب — كل باب داخله خدمة مختلفة:

:80
HTTP 🌐
مواقع الإنترنت (غير مشفرة)
:443
HTTPS 🔒
المواقع المشفرة
:22
SSH 🖥️
التحكم عن بُعد في Linux
:21
FTP 📁
نقل الملفات (قديم وخطير!)
:3389
RDP 🪟
سطح مكتب Windows عن بُعد
:53
DNS 📖
ترجمة الأسماء لعناوين

💡 في المبنى فيه 65,535 باب (منفذ) — وكل خدمة بتفضل تسمع على بابها. لو باب مفتوح على خدمة قديمة أو مؤمنة غلط... ده مدخل الهجوم! ولية ده أهم مفهوم في اختبار الاختراق.

🚦 حالات المنفذ الثلاثة — إزاي Nmap بيشوفهم

open

الباب مفتوح وفيه خدمة شغالة — ده المطلوب نعرفه! 🟢

closed

الباب مقفول — مفيش خدمة سماعة عليه 🔴

filtered

جدار حماية بيمنع الوصول — مش عارفين لو مفتوح ولا لأ 🟡

🎓
مصطلحات النهاردة:
Port Scanning = فحص المنافذ | Service Detection = اكتشاف الخدمات | Banner = البطاقة التعريفية اللي بيرد بيها الخدمة (فيها الإصدار!)

3 ⚖️ القاعدة الذهبية — قبل أي أمر

🚨
أهم جزء في المحاضرة كلها — اقرأه مرتين:
Nmap أداة فحص نشط — يعني بتبعت حزم حقيقية للهدف، والهدف بيشوفك ويعرف إنك بتفحصه. علشان كده القانون في كل البلاد واضح:

✅ مسموح: فحص أجهزتك أنت + أجهزة اللاب المعزولة (الـ VMs بتوعنا)
🚫 ممنوع: فحص أي جهاز أو موقع أو شبكة من غير إذن مكتوب — حتى لو "بس بسأل ألوان"!

الفرق بين الاثنين؟ الأول مهنة اسمها Ethical Hacker والتاني... ملف قضية 👮‍♂️
كل تمرين النهاردة داخل عالم VirtualBox المعزول — مفيش أي خروج للإنترنت.
💼
معلومة سوق الشغل: أي شركة اختبارات اختراق حقيقية بتوقع مع العميل ورق تفويض (Scope & Authorization) قبل لمس أي جهاز. المحترف بيفحص اللي مسموح له بيه بس — دي أول قاعدة في الـ CEH و OSCP.

4 💻 أدوات النهاردة — أوامر Nmap خطوة بخطوة

1️⃣ nmap -sn — "مين حي هنا؟" 📡

kali@sunshine — Host Discovery
kali@sunshine:~$ nmap -sn 192.168.10.0/24
Starting Nmap 7.94 ( https://nmap.org )
Nmap scan report for 192.168.10.1
Host is up (0.0012s latency).
Nmap scan report for 192.168.10.50
Host is up (0.0045s latency).
Nmap done: 256 IP addresses (2 hosts up) scanned in 2.31 seconds

🔎 التفسير: -sn = "سأل بس، ما تدخلش الأبواب" — بيسأل كل العناوين الـ 256: "في حد؟" — والنتيجة: جهازين حيين بس. الـ latency = زمن الرد (نفس time بتاع ping!)

2️⃣ nmap IP — "الأبواب بتاعت واحد فيهم إيه؟" 🚪

kali@sunshine — Port Scan
kali@sunshine:~$ nmap 192.168.10.50
PORT STATE SERVICE
21/tcp open ftp
22/tcp open ssh
80/tcp open http
3389/tcp closed ms-wbt-server

🔎 التفسير: الجهاز ده عنده 3 أبواب مفتوحة (FTP, SSH, HTTP) وباب واحد مقفول. المحلل الأمني هنا بيسأل: ليه خالص مفتوح FTP؟ ده بروتوكول قديم مشفر أبدًا! 🤔

3️⃣ nmap -sV — "أنهي إصدار من الخدمة ده؟" 🔍

kali@sunshine — Version Detection
kali@sunshine:~$ nmap -sV 192.168.10.50
PORT STATE SERVICE VERSION
21/tcp open ftp vsftpd 2.3.4
22/tcp open ssh OpenSSH 8.4p1
80/tcp open http nginx 1.18.0
💡
لحظة "آها!" للطلبة: اكتشفنا إن الـ FTP هو vsftpd 2.3.4 — لو بحثنا في Google عن "vsftpd 2.3.4 vulnerability" هنلاقي إن الإصدار ده فيه ثغرة مشهورة!
دي أهم فكرة في اختبار الاختراق كلها: الإصدار القديم = ثغرات معروفة. المحلل بيجمع المعلومة دي ويدوّنها في التقرير، وبيوصي بتحديث الخدمة. من غير ما يهجم على حاجة!

4️⃣ nmap -O — "نظام التشغيل إيه؟" 🧠

kali@sunshine — OS Detection
kali@sunshine:~$ sudo nmap -O 192.168.10.50
Device type: general purpose
Running: Linux 3.X
# لاحظوا sudo! فحص نظام التشغيل محتاج صلاحيات أعلى — افتكروا المحاضرة 2 😉

💡 إزاي بيخمن؟ كل نظام تشغيل بيتبع الحزم بطريقته الخاصة (تشيلات مختلفة في الـ TCP flags و TTL). Nmap بيحط كل الطرق دي في "بصمة" (Fingerprint) ويقارنها بقاعدة بيانات ضخمة. زي البصمة في Crime Scene Investigation! 🕵️

5️⃣ -oN — احفظ التقرير زي المحترفين 📄

kali@sunshine — Output to File
kali@sunshine:~$ nmap -sV 192.168.10.0/24 -oN lab_scan.txt
# -oN = Output Normal → كل النتيجة بتتحفظ في ملف نصي
kali@sunshine:~$ cat lab_scan.txt
...تقرير كامل جاهز للعرض على المدير! 📊

🧰 ملخص الأعلام (Flags) — تثبيت المحتوى

-sn

اكتشاف الأجهزة الحية بس — "مين موجود؟"

-sV

معرفة الخدمات والإصدارات — "بيشتغلوا بنسخة إيه؟"

-O

تخمين نظام التشغيل (محتاج sudo)

-p 1-1000

فحص منافذ محددة أو نطاق منها

-oN file.txt

حفظ النتيجة في تقرير نصي

-v

عرض تفاصيل أكتر أثناء الفحص (verbose)

5 🕵️ لعبة اليوم: «مين هو الجهاز؟» — تحقيق استخباراتي

🏴 السيناريو

المدرّس شغّل 3 أجهزة هدف (Targets) في الشبكة المعزولة — كل واحد فيهم شخصية مجهولة:

🎯

الجهاز A

مجهول تمامًا — مهمتكم اكتشفوا شخصيته!

🎯

الجهاز B

مجهول — استخدموا كل مهاراتكم

🎯

الجهاز C

مجهول — الأصعب على الإطلاق!

مثلاً: واحد فيهم ويب سيرفر، وواحد راوتر، وواحد جهاز Linux عنده SSH — إنتوا اكتشفوا!

1

اكتشفوا مين حي

nmap -sn 192.168.10.0/24 — سجّلوا العناوين اللي ردت

2

افحصوا الأبواب

nmap على كل هدف — المنافذ المفتوحة هتلمحكم للشخصية

3

أكّدوا بالتفاصيل

sudo nmap -sV -O — الإصدار ونظام التشغيل هيكشفوا الحقيقة

4

قدّموا الادعاء 🏛️

اكتبوا في الورقة: "الجهاز A = [الشخصية]" + سبب الاستنتاج (أهم جزء!) — والفريق الأدق يفوز

🏆 لقب النهاردة: "Digital Detective" (المحقق الرقمي)!

🎯
الدرس الأعمق من اللعبة: ده اسمه Fingerprinting — جمع بصمة الهدف من معلومات صغيرة متفرقة. نفس المهارة دي بالظبط بيستخدمها الهاكر الأخلاقي والمحلل الأمني والمحقق الجنائي الرقمي. انتوا اتعلمتوها وهي لسا لعبة! 😉

🛠️ التمرين الرئيسي — تقرير الفحص الأمني 📋 (45 دقيقة)

🎯 السيناريو: أول Missions حقيقية لكم كفريق أمني

"شركة Sunshine Test Lab قعدت تستأجر فريقكم لعمل Security Assessment لشبكتها المعزولة (النطاق المسموح: 192.168.10.0/24). المطلوب تقرير شامل."

1

حصر الأصول (Asset Discovery)

nmap -sn 192.168.10.0/24 -oN 1_hosts.txt
كم جهاز حي؟ دوّنهم.

2

فحص الخدمات (Service Scan)

sudo nmap -sV -O 192.168.10.0/24 -oN 2_services.txt
(هتاخد 2-3 دقايق — وقت مثالي للنقاش!)

3

التحليل والاستنتاج

لكل جهاز اكتب في ملف findings.txt (بـ nano):
العنوان → المنافذ المفتوحة → الخدمات والإصدارات → ملاحظة أمنية

4

التوصيات (Recommendations)

اكتب على الأقل تنيين توصية، مثال حقيقي:
✅ "الخدمة FTP القديمة على جهاز X — توصية: تعطيلها واستبدالها بـ SFTP"
✅ "SSH مفتوح لكل الشبكة — توصية: تقييده بعناوين محددة"

📄
معلومة تشجيعية: التقرير اللي كتبتوه النهاردة هو نفس شكل المُخرَج اللي شركات الـ Pentesting بتسلمه للعملاء وبتتقاضى عليه آلاف الجنيهات! طبعًا نسخة مبسطة، بس نفس الفكرة ونفس البنية — انتوا كتبوا أول تقرير أمني في حياتكم 🎉

5 🧠 اختبر نفسك — كويز تفاعلي

❓ سؤال 1: المنفذ 22 المفتوح معناه غالبًا إن الجهاز فيه...؟
❓ سؤال 2: الفرق الأساسي بين nmap -sn و nmap العادي؟

❓ سؤال 4: صاحبك طلب منك تفحص شبكة جارهم "للمرح" — تعمل إيه؟

📌 خلاصة المحاضرة + الواجب

📡 nmap -sn — اكتشاف الأجهزة الحية في الشبكة كلها بأمر واحد
🚪 المنافذ — أبواب المبنى: open / closed / filtered
🔍 -sV — الخدمات والإصدارات: الإصدار القديم = ثغرة محتملة
🧠 -O — بصمة نظام التشغيل (محتاج sudo!)
📄 -oN — تقرير مكتوب — عادة المحترفين من أول يوم
⚖️ الإذن — فحص اللي مسموحلك بيه بس — القانون قبل الأداة

📝 الواجب المنزلي

  1. سلّم تقرير الفحص (الملفات الثلاثة: hosts + services + findings) — منسق ونظيف
  2. في ملف homework4.txt: اشرح بكلامك الفرق بين open و filtered وليه الـ Firewall بيرجع حالة تالتة أصلاً
  3. ❓ سؤال التفكير: لو الجهاز "بيدّيping" لكن nmap -sn ما لقاهوش — إيه الاحتمالات؟ (تلميح: الجدار الناري بيمنع الـ ICMP... ابحث عن "nmap ping blocked")
  4. 🎁 اختياري للباحثين: شغّل nmap --help وعدّي عليا 3 flags مش شرحناهم النهاردة واكتب مين بيعمل إيه — الفريق اللي يجيب أغرب واحد ياخد نقاط!
